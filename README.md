# amerika.by — новый сайт

Тестовая версия живёт в папке `new/` и выкладывается на хостинг в `amerika.by/new/` (рядом с файлами WordPress, живой сайт не затрагивается).

- `new/index.html` — главная «Пригон авто из США»: оффер, калькулятор стоимости до Минска, шаги работы, цены, FAQ, форма заявки.
- Все ставки калькулятора (курсы, сборы аукциона, логистика, пошлины) собраны в объекте `CONFIG` в конце файла.
- `CONFIG.leadEndpoint` — адрес вебхука для заявок в amoCRM; пока пустой, форма работает в тестовом режиме.
- Страница закрыта от индексации (`noindex`) до запуска.

Выкладка: заархивировать содержимое `new/`, загрузить через файловый менеджер хостинга в папку `new` в корне сайта и распаковать.

## Каталог лотов `catalog/`

Страница `amerika.by/catalog/` (noindex): живые лоты Copart и IAAI через AuctionsAPI.

- `catalog/index.html` — фильтры, плитка или список, окно лота с фото, ценой, резервом продавца и историей по VIN.
- `catalog/api.php` — серверный прокси. Браузер ходит только сюда, ключ API наружу не попадает. Кэширует ответы и считает запросы (демо-ключ даёт 100 запросов, прокси останавливается на 90; сбросить счётчик = удалить `catalog-cache/budget.json`).
- `catalog/sample.js` — примерные лоты; показываются, пока ключа нет.

Ключ кладётся одной строкой в файл `/home/i/infoamvz/amerika.by/auctionsapi.key` (на уровень выше `public_html`, из интернета недоступен). Кэш пишется в `/home/i/infoamvz/amerika.by/catalog-cache/`.
