# amerika.by — новый сайт

Тестовая версия живёт в папке `new/` и выкладывается на хостинг в `amerika.by/new/` (рядом с файлами WordPress, живой сайт не затрагивается).

- `new/index.html` — главная «Пригон авто из США»: оффер, калькулятор стоимости до Минска, шаги работы, цены, FAQ, форма заявки.
- Все ставки калькулятора (курсы, сборы аукциона, логистика, пошлины) собраны в объекте `CONFIG` в конце файла.
- `CONFIG.leadEndpoint` — адрес вебхука для заявок в amoCRM; пока пустой, форма работает в тестовом режиме.
- Страница закрыта от индексации (`noindex`) до запуска.

Выкладка: заархивировать содержимое `new/`, загрузить через файловый менеджер хостинга в папку `new` в корне сайта и распаковать.
