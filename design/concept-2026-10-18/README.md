# Предложение дизайна, 18 октября 2026

Эскиз Codex для обсуждения с Леонидом. Это предложение, не согласованный финальный дизайн. По просьбе Леонида публикуется отдельно на https://amerika.by/newcodex/; страница цен — https://amerika.by/newcodex/prices.html.

Основа: ветка `claude/project-thread-ph3goc`, коммит `54ae8ee`. Рабочие шаблоны `site/` и собранный сайт `new2/` не изменены.

## Просмотр

На хостинг в отдельную папку `public_html/newcodex/` выкладываются только `index.html`, `prices.html`, `style.css`, `app.js` и `assets/`. Обе страницы содержат `noindex,nofollow`. Главная WordPress и `/new2/` при публикации не меняются. Доступ: существующий SSH-алиас `amerika-beget`; секретов в репозитории нет.

Откройте `preview.html` в браузере: главная и цены работают без сервера и интернета. Изображения, CSS и JS встроены. После правки исходников обновите файл командой `node design/concept-2026-10-18/make-preview.cjs` из корня репозитория.

Исходники: `index.html`, `prices.html`, `style.css`, `app.js`, `assets/`. Для просмотра вместе с исходным сайтом можно запустить `python -m http.server 8876 --bind 127.0.0.1` из корня репозитория и открыть `/design/concept-2026-10-18/`. Ссылки «Версия Claude», каталог, блог и дилерам ведут на соседний сохранённый `new2/`.

## Предлагаемые изменения

- Сохранить бренд: кремовый фон, тёмно-синий, красный и небольшой жёлтый акцент. Крупная фотография реального автомобиля из существующего каталога на первом экране; не выдавать её за выполненный заказ или наличие автомобиля в Минске.
- Один основной призыв «Подобрать авто» и второй путь «Посчитать стоимость». Гарантии договора, прямой оплаты и офиса — компактной полосой.
- На главной три карточки вместо шести подробных таблиц. Главный показатель — стоимость готовой машины; детализация открывается по нажатию.
- Не выбирать льготу за посетителя. В примерах показан итог без льготы с резервом восстановления. Точный расчёт рабочего сайта должен зависеть от конкретного лота, состояния и права покупателя на льготу.
- Четыре этапа работы, короткий блок стоимости услуги, ответы на ключевые вопросы и одна форма. Ссылки на каталог, блог и дилерский раздел сохраняются.
- Отдельная страница цен объясняет три сценария участия клиента. 590/990/1999 BYN и состав услуг взяты из последней ветки Claude; это не новое изменение прайса.

## Данные и границы

Числа 17700 / 18200 / 17200 USD для Equinox / Terrain / Jetta взяты из строк без льготы в `new2/index.html` исходного коммита. Из них условный резерв восстановления 1500 USD выделен отдельно. `site/data/home-models.json` прямо помечает цены покупки и восстановления как черновые: подтверждение Леонида ещё требуется. Примеры не являются рыночным расчётом, действующим предложением или утверждённой сметой; это явно отмечено на страницах.

Фотографии карточек скопированы с URL, уже использованных в исходном `new2/index.html`; логотип из `new2/img/logo.svg`. Водяные знаки не удалялись. Наличие автомобиля, его техническое состояние и права на рекламное использование изображений в этой работе не подтверждались.

По просьбе Леонида первый экран обновлён: `assets/hero-light-suv.webp` — новая декоративная AI-иллюстрация серебристо-голубого кроссовера на светлом фоне, созданная встроенным Imagegen. Она явно обозначена как иллюстрация, не связана с конкретным лотом, годом, наличием или ценой. Исходный PNG хранится в локальной папке generated_images, WebP оптимизирован до 196022 байт. Полный запрос — `hero-image-prompt.txt`. Затемнение фотографии снято; этапы, подвал и выделенный тариф получили светлый голубовато-серый фон.

В прототипе нет аналитики, API и отправки заявок. Форма только показывает локальное сообщение; данные не сохраняются. Внешние телефонные и Telegram-ссылки настоящие.

## Проверено

Главная и цены на ширинах 1440, 390 и 360 пикселей: без горизонтального переполнения и сломанных изображений. Проверены выбор модели, вкладка бюджета, передача пожеланий в форму, окно состава цены и Escape, мобильное меню, выбор тарифа, отсутствие POST при демонстрационной отправке. Отдельный HTML проверяется без сети перед передачей.

## Что объединить с последней версией Claude

Сравнение с коммитом Claude `54ae8ee` от 18.10.2026, а не с более старой опубликованной `/new2/`. Ниже рекомендации Codex, а не утверждённые бизнес-решения.

| Часть | Предлагаемое решение |
| --- | --- |
| Основа сайта | Сохранить генератор Claude `site/`, данные каталога и блога, страницы машин, услуг, дилеров, контактов и действующие адреса. Перенести выбранный дизайн в шаблоны, а не содержать две независимые версии. |
| Главная | Светлая подача Codex, крупный автомобиль, один главный призыв и компактные гарантии. Из Claude сохранить конкретику о договоре, оплате и доставке; вернуть короткий блок дилеров и полезные статьи. |
| Калькулятор | Использовать расчётное ядро Claude и поиск по моделям, оформить проще. Наш переключатель с тремя фиксированными ценами — только демонстрация, не замена калькулятору. |

| Доверие | Конкретные ответы и этапы Claude; компактная верстка Codex. Добавлять реальные примеры доставки и отзывы из подтверждённых материалов компании. |

### Что закрыть до запуска

1. Единый итог стоимости. В `site/build.mjs` карточки прибавляют `m.repair`; быстрый калькулятор `site/assets/site.js` сравнивает рынок с `costOf(...).total`. В `site/assets/calc-core.js` ремонт в сумму не входит. Следовательно, показанная быстрым калькулятором разница с рынком сейчас не учитывает восстановление. Это нужно исправить до публикации обещаний экономии. В карточках Claude основной итог со льготой, строка без льготы ниже; в быстром калькуляторе уже стоит `benefit:false`.
2. Подтвердить цены покупки и восстановления в `site/data/home-models.json`, актуальность курсов/логистики и помеченных TODO сборов в `site/assets/config.js`; не делать из одинакового резерва 1500 USD оценку конкретного лота.
3. Подключить реальный приём заявок и проверить доставку тестовой заявки менеджеру: `CONFIG.leadEndpoint` пустой. Подключить аналитику и проверить цели: идентификаторы счётчиков тоже пустые.
4. Собрать все страницы в едином оформлении, проверить мобильные переходы, фото и формы. При окончательном запуске проверить адреса/редиректы и индексацию: сейчас версии тестовые, с noindex.

Рекомендация: завершать рабочую основу Claude, перенося в неё светлый дизайн и более простую подачу Codex. Одна система данных и один расчёт для карточек, калькулятора и заявки.
