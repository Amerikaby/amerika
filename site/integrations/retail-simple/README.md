Марка, модель, год, объём, двигатель, порт, аукцион и площадка имеют список и поиск с клавиатуры. Списки поддерживают стрелки, Enter, Escape и нажатие кнопки раскрытия; русские названия распространённых марок и моделей сопоставляются с оригинальными.

Лот запрашивается только после «Найти лот» или Enter через уже установленный Amerika Auction Pilot (`amap_bootstrap`, `amap_tools`). Ключ, разрешения и лимиты не изменены. Новый внешний провайдер не подключался. Справочник марок/моделей грузится по обращению к полю, а не на каждый символ. Серверный кеш и ограничения остаются в существующем плагине.

Подставляются только факты источника: марка/модель, год, известный двигатель, аукцион и точно сопоставленная площадка. Неизвестные характеристики остаются для ручного ввода, неоднозначное название площадки не заменяется похожим. Текущая ставка не выдаётся за финальную цену: в режиме цены после поиска лота требуется ввести планируемую покупку. Ремонт не оценивается по ставке/названию автомобиля. Марка и модель из справочника сами по себе не определяют единственный двигатель или год.

Если поиск не удался, данные можно ввести вручную после очистки номера. Пока введён новый неподтверждённый лот или обязательное поле не выбрано, прежняя сумма не может быть отправлена как новый расчёт. Марка, модель и введённый номер/ссылка входят в сводку заявки и ссылку для повторного открытия расчёта. Открытие ссылки не вызывает автоматический платный поиск лота.
