# Упрощённый калькулятор — версия для просмотра

Адрес: `https://amerika.by/newcodex/kalkulyator-simple/`. Основной `/kalkulyator/` и меню не изменены. Страница использует существующие шапку, подвал, палитру, форму заявки, розничные тарифы и общий снимок НБРБ. `noindex, nofollow`; `DONOTCACHEPAGE` объявлен до WordPress bootstrap, чтобы Rocket не сохранял старый эскиз. Родитель `/newcodex/.htaccess` назначает index.html; локальная `.htaccess` назначает index.php только этой папке.

На первом плане — номер лота, основной ввод автомобиля, цена/бюджет, порт и итог. Площадка/аукцион, ремонт/льгота/услуга и подробная смета раскрываются отдельно. В итоге видны пять групп затрат. Марка, модель, год, объём, двигатель, порт, аукцион и площадка имеют список и поиск с клавиатуры. Списки поддерживают стрелки, Enter, Escape и нажатие кнопки раскрытия; русские названия распространённых марок и моделей сопоставляются с оригинальными.

Лот запрашивается только после «Найти лот» или Enter через уже установленный Amerika Auction Pilot (`amap_bootstrap`, `amap_tools`). Ключ, разрешения и лимиты не изменены. Новый внешний провайдер не подключался. Справочник марок/моделей грузится по обращению к полю, а не на каждый символ. Серверный кеш и ограничения остаются в существующем плагине.

Подставляются только факты источника: марка/модель, год, известный двигатель, аукцион и точно сопоставленная площадка. Неизвестные характеристики остаются для ручного ввода, неоднозначное название площадки не заменяется похожим. Порт **прибытия** предлагает прежняя функция маршрута калькулятора; поле `send_from` источника обозначает отправление из США и для этого не используется. Любой предложенный маршрут можно изменить. Текущая ставка не выдаётся за финальную цену: в режиме цены после поиска лота требуется ввести планируемую покупку. Ремонт не оценивается по ставке/названию автомобиля. Марка и модель из справочника сами по себе не определяют единственный двигатель или год.

Если поиск не удался, данные можно ввести вручную после очистки номера. Пока введён новый неподтверждённый лот или обязательное поле не выбрано, прежняя сумма не может быть отправлена как новый расчёт. Марка, модель и введённый номер/ссылка входят в сводку заявки и ссылку для повторного открытия расчёта. Открытие ссылки не вызывает автоматический платный поиск лота.

Сборка: `node site/integrations/retail-simple/build-preview.mjs` создаёт preview-body.php и retail.js из действующей интеграции. Финансовая часть до UI-обёртки остаётся побайтово той же; правки касаются отображения результата, полноты сводки, проверки завершённости ввода и адреса ссылки. Новые UI-файлы: preview.js, preview.css, index.php.

Проверки: `node site/tools/check-retail-simple.cjs` и существующий `check-retail-calculations.cjs`. До переноса в основной калькулятор требуется просмотр Леонида; перенос в этом этапе не выполняется.
