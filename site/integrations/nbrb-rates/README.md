# Единый курс НБРБ для действующего WordPress

`amz-nbrb-rates.php` устанавливается в `wp-content/mu-plugins/`. Все денежные значения — BYN за **одну** единицу валюты. USD/EUR принимаются одной парой с официальной датой; RUB нормализуется с учётом `Cur_Scale`.

Источник: `https://api.nbrb.by/exrates/rates?ondate=YYYY-MM-DD&periodicity=0`. Проверяются HTTP-статус, дата, обе валюты, конечные положительные значения и масштаб. Последний проверенный снимок хранится в опции `amz_nbrb_last_good`; попытки обновления — каждый час и при смене даты, с блокировкой и паузой повторов при ошибке. При сбое сохраняется настоящая дата прежних курсов. Пустой снимок не заменяется придуманным курсом.

- PHP: `amz_nbrb_snapshot()` и совместимые фильтры старых опций/транзиентов цен.
- Браузер: синхронный `/?amz_nbrb=js` в `wp_head`, объект `window.AMZ_NBRB`.
- Проверка: `/?amz_nbrb=json`, ответ с `no-store`.
- EUR/USD вычисляется как точное отношение EUR/BYN к USD/BYN; округляется только подпись.

Файлы `legacy/` соответствуют действующим путям темы `js/` и плагину `tamozh-calculator/tamozh-calculator.php`. В двух готовых webpack-сборках заменён модуль валютных данных и инициализация курса; логистические тарифы сохранены. Скрипты в защищённых оптовых страницах получают `ver=20261021.1` через узкий фильтр HTML. Доступ по паролю сохраняется.

Розничный потребитель находится в `../retail-calculator/`. Таможенный калькулятор переводит введённую стоимость из выбранной валюты в EUR перед применением прежних ставок пошлины. Структура форм и стили сохранены.

Перед установкой нужны адресные копии за пределами document root и первоначальный проверенный снимок официальных данных. После установки: `rocket_generate_config_file()`, очистка минифицированных ресурсов и HTML-кеша; проверить заголовки endpoint и порядок загрузки. WP-Cron зависит от трафика/задания хостинга. При недоступном API нельзя считать автоматическое обновление подтверждённым только по наличию задания.

Проверки:

```sh
php site/tools/check-nbrb-provider.php
node site/tools/check-legacy-nbrb.cjs
node site/tools/check-retail-calculations.cjs
```

Это интеграция основного WordPress-сайта. Статические архивы прототипов в `/new*` не входят в неё.
