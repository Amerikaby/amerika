# Быстрый / подробный калькулятор · тест 28.10.2026

Адрес: https://amerika.by/newcodex/kalkulyator-quick/. Основной `/kalkulyator/`, меню и существующая форма не заменены. Это конкретный вариант для просмотра Леонидом, с теми же шапкой, подвалом, палитрой и финансовыми ставками.

## Согласованные требования

- По умолчанию открывается быстрый режим: цена лота без сборов, тип автомобиля. По уточнению Леонида основной итог включает покупку, сборы, доставку и услугу, **без таможни и ремонта**. Доставка показана отдельно.
- Клайпеда — начальный ценовой пример; автоматически выбрана минимальная полная подтверждённая доставка по США + море + конечный участок. Только американские площадки с известным штатом и `seaConfirmed=true`. В снимке 28 октября минимальна Copart ATLANTA EAST - GA: около2950USD черезКлайпеду /4565USD черезПоти. Это не площадка фактического лота.
- В раскрытии — ручной порт, площадка с вводом букв/подсказками, возраст, двигатель, клиренс и необязательное добавление таможни. Неизвестная площадка блокирует сумму. Ручной выбор площадки сохраняется при смене порта.
- Типы: легковой, кроссовер, крупныйSUV/пикап. Утверждённых розничных надбавок за габариты нет. Для последних двух показан базовый тариф с «от ≈» и видимой пометкой о неучтённой доплате; выбор передаётся менеджеру. **Ценовая разница размеров ещё не реализована**, нужны подтверждённые тарифы.
- Подробный режим сохраняет существующие поля. Цена, маршрут, возраст/двигатель/клиренс переносятся при наличии независимо; неуказанные характеристики помечены примером. Режимы сохраняют своё состояние, переключение без новых быстрых правок не сбрасывает подробный расчёт.
- Это предварительная оценка. Инвойс не формируется: менеджер проверяет лот и выставляет счёт. Контакты/readonly-сводка доступны; CF7 shortcodes подавлены только в этой тестовой странице, включая общую шапку/подвал. Отдельные глобальные REST/POST сайта не менялись.

## Правило маршрута от Саши Ганковича

Сообщение от28.10.2026 21:20, передано Леонидом; запись amerika#13236. Леонид отдельно подтвердил, что клиренс относится только к авто старше пяти лет.

- Авто до5лет включительно: Клайпеда при двигателе до1900см³.
- Авто старше5лет: любой объём, Клайпеда при клиренсе<=165мм. При неизвестном клиренсе — предварительноПоти.
- Мото: цена+сборы+сушаСША+море доКлайпеды<=5000USD включительно. Последний участок, таможня, услуга и ремонт в этот порог не входят.
- Остальное —Поти. Дата выпуска и фактические характеристики проверяются менеджером. Гибриды/электро остаются отдельным подтверждением, по прежнему осторожному сценариюПоти.

`routeDecision` различает allowed/denied/unknown. Без параметров быстрая Клайпеда явно обозначена ценовым примером без подтверждения доступности. Проверка маршрута не зависит от включения таможни. Заведомо неподходящий ручной выборКлайпеды блокирует итог. Мото в режиме бюджета ограничивает максимальную ставку одновременно бюджетом и порогом5000USD; перебор не более101ставки с шагом50USD.
