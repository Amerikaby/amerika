## Режимы и заявки

- Быстрый: цена лота и класс автомобиля; итог включает покупку, сборы аукциона, доставку и услугу, без таможни и ремонта. Доставка показана отдельно. По желанию можно раскрыть порт, площадку, двигатель, возраст, клиренс и добавить таможню.
- Без характеристик Клайпеда — явно неподтверждённый ценовой пример. Автоматом выбирается минимальная полная доставка среди подтверждённых американских площадок; для размера прежде предпочитаются маршруты с известными размерными тарифами. Ручную площадку можно ввести с подсказкой. Неизвестное имя блокирует итог.
- Подробный сохраняет поиски марки/модели/площадки, импорт лота, цену/бюджет, двигатель, год, порт, Sublot, ремонт, льготу и услугу. Добавлен размер автомобиля. Незаданные в быстром параметры подробного режима явно остаются примером. Переключение без новых быстрых правок сохраняет подробное состояние.
- Ремонт по умолчанию0, нулевая строка скрыта, льгота50% включена; явный `benefit=0` из URL сохраняется. Все режимы используют общий НБРБ.
- CF7 форма17910 / страница17911. Оригинальный `retail-simple/form-transport.js` сохранён побайтово; нативный CF7 POST → WordPress outbox → `/opt/amerika-leads` → amoCRM и Telegram. Перед сериализацией пересчитывается именно активный режим. Невалидные поля очищают старую сводку, недостаточный бюджет блокируется. Hidden fields: calc-params, calc-result, post-url. Подробная заявка содержит класс, известные надбавки, неизвестные расходы, максимальную ставку или явное отсутствие подтверждённой ставки.
- Это предварительная оценка, не инвойс. При неизвестных надбавках бюджетный режим не показывает рекомендацию «можно ставить до»; менеджер должен подтвердить расходы.
